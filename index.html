Good to
know.

Beberapa hal penting sebelum kamu mulai menggunakan workspace ini.

Tidak. Tradeops adalah alat bantu perencanaan, pencatatan, dan evaluasi. Platform ini tidak menyediakan sinyal, rekomendasi aset, atau jaminan keuntungan.
Fitur pencatatan menggunakan localStorage pada browser. Data tidak otomatis dikirim ke server oleh kode ini. Backup JSON berisi informasi transaksi kamu.

Tidak. Hasilnya simulasi matematis dengan asumsi return tertentu. Return aktual bisa negatif atau berbeda dari asumsi. Setoran tambahan bukan keuntungan trading.
